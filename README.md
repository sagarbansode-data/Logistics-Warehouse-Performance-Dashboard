# 📊 Logistics & Warehouse Performance Dashboard

## 📌 Project Overview

This project demonstrates the development of a business-driven Power BI reporting solution for warehouse inventory and supply chain operations.

The solution was built using a PostgreSQL database and Power BI to help warehouse managers, operations teams and executive leadership monitor operational performance, inventory health and warehouse efficiency.

The dashboards were developed based on four corporate stakeholder requirement documents, where each phase introduced new business challenges and reporting requirements.

---

# 🏢 Business Scenario

A US-based logistics organization was facing operational challenges across multiple warehouse distribution centres, including:

- Inventory movement monitoring
- Warehouse performance
- Inventory discrepancies
- Validation failures
- Task productivity
- Supplier performance
- Executive KPI reporting

The organization required interactive Power BI dashboards capable of supporting operational teams and executive management with data-driven decision making. :contentReference[oaicite:2]{index=2}

# 🚀 How to Open the Project

1. Clone this repository.
2. Open the required `.pbix` file using Microsoft Power BI Desktop.
3. If prompted, reconnect the data source to your own PostgreSQL database.
4. Refresh the data model.
5. Explore the dashboards using available filters and slicers.
